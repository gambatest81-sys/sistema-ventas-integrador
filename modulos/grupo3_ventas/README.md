# Módulo de Ventas POS — HTML / CSS / JavaScript

Conversión del proyecto original a HTML, CSS y JavaScript vanilla.

- No React
- No TypeScript
- No Vite
- No se agregaron campos al formulario de registro de cliente.
- Se conservan los datos, textos y reglas de negocio presentes en el proyecto original.
- `index.html` es el punto de entrada.
- `app.js` contiene el estado y la lógica.
- `styles.css` contiene los estilos.

Nota: los iconos utilizan Lucide desde CDN para reemplazar `lucide-react` sin introducir un framework.
